# Food-Vision-Classifier
It is an end-to-end Binary **Image Classifier** built using **Computer Vision**. 

File names starting with `Transfer_Learning.....` are notebooks containing some experiments conducted by me while learning Transfer Learning.

In `main_Food_Vision.ipynb`, i have beat the score achieved by the `Food101` model.

# The dataset used : 
https://storage.googleapis.com/ztm_tf_course/food_vision/pizza_steak.zip
https://storage.googleapis.com/ztm_tf_course/food_vision/10_food_classes_10_percent.zip
